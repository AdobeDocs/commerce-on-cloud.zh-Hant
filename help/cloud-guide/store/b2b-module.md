# 啟用B2B模組

如果您的客戶為公司，您可以安裝Adobe Commerce B2B模組，將Adobe Commerce擴充至雲端基礎結構Pro專案，以符合企業對企業的模式。 您可以在[Adobe Commerce B2B使用手冊](https://experienceleague.adobe.com/zh-hant/docs/commerce-admin/b2b/guide-overview)中找到在雲端基礎結構上安裝和設定Adobe Commerce B2B模組的資訊。
